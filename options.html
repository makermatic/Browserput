Browserput

1. Device access

To list your outputs by name, the browser needs permission to see your audio devices. It asks for microphone access because that's how Chromium handles it. The extension opens the mic for a moment to get the permission, closes it straight away, and never records anything.

2. Your outputs

    4. Save file & backup

    Your saved sites live in the extension's storage inside your Brave profile. Extensions can't read or write files anywhere else on disk, so there isn't a file location to choose. Use these buttons to keep a copy or move your setup to another computer.

    5. Automatic routing

    Brave only lets an extension capture a tab after you click it on that tab. Without automatic routing, a newly opened tab for a saved site shows an orange ▶ badge until you click the icon (or press the shortcut). Extensions aren't allowed to change this themselves, but a one-time setup on your computer can:

    1. Open the Browserput folder you loaded into Brave, then the windows folder.
    2. Double-click Set up automatic routing.cmd and type 1. If Windows says it protected your PC, click More info → Run anyway.
    3. Fully close Brave (including its icon near the clock, if there is one) and open it again.

    It adds this setting to your Brave shortcuts. It lets only Browserput capture tabs by itself. Run the same file and type 2 to undo it.
